Direction locked: **full visual redesign, existing structure retained**, industrial palette

Companion file: `design-system/guvenay-insaat/MASTER.md` (generated by the ui-ux-pro-max skill).

## 0. Critical correction to the skill's palette

The skill emitted `--color-accent: #EA580C` with the note *"adjusted for WCAG 3:1"*. That 3:1
target only covers **large text and UI components**. Measured:

| Pair | Ratio | AA normal text (4.5) |
|------|-------|----------------------|
| `#EA580C` text on `#F8FAFC` | 3.40 | **FAIL** |
| `#FFFFFF` on `#EA580C` fill | 3.56 | **FAIL** |
| `#FFFFFF` on `#C2410C` fill | 5.18 | PASS |
| `#C2410C` text on `#F8FAFC` | 4.95 | PASS |

**Consequence:** a solid `#EA580C` button with white label is not AA-compliant. Split the accent
into two roles and never collapse them:

- `--accent` `#EA580C` — large display type (≥24px bold), icons, rules, focus rings, hairline emphasis
- `--accent-strong` `#C2410C` — **any filled control carrying white text**, and accent-colored body text

## 1. Token set (verified)

All pairs below were measured with the WCAG relative-luminance formula. Every one passes its
target. Define these in `src/index.css` via Tailwind v4 `@theme` so they become real utilities
(`bg-surface`, `text-muted`, …) instead of inline styles.

### Light (`:root`)

| Token | Hex | Verified use |
|-------|-----|--------------|
| `--bg` | `#F8FAFC` | page base |
| `--bg-alt` | `#EBF0F5` | alternating section band |
| `--surface` | `#FFFFFF` | cards |
| `--ink` | `#0F172A` | dark contrast band; white on it = 17.85 |
| `--text` | `#0F172A` | headings — 17.06 on bg |
| `--text-soft` | `#334155` | body — 9.90 on bg |
| `--text-dim` | `#64748B` | captions — 4.55 on bg (at AA floor; do not lighten) |
| `--accent` | `#EA580C` | large type / icons / rules only |
| `--accent-strong` | `#C2410C` | filled CTAs + accent body text |
| `--border` | `#E2E8F0` | decorative dividers only |
| `--border-control` | `#64748B` | **form/control boundaries — 4.55, meets 1.4.11** |

### Dark (`:root[data-theme="dark"]`, default via `prefers-color-scheme`)

Tonal variants, not inversions (skill rule `color-dark-mode`).

| Token | Hex | Verified use |
|-------|-----|--------------|
| `--bg` | `#0B1220` | page base |
| `--bg-alt` | `#111A2B` | section band |
| `--surface` | `#151E2E` | cards — body text on it = 11.25 |
| `--text` | `#F1F5F9` | headings — 17.09 |
| `--text-soft` | `#CBD5E1` | body — 12.61 |
| `--text-dim` | `#94A3B8` | captions — 7.30 |
| `--accent` | `#FB923C` | lightened for dark — 8.27; also takes `#0B1220` text at 8.27 |
| `--accent-strong` | `#EA580C` | 5.26 — usable as text here, unlike in light |
| `--border-control` | `#5A6B80` | 3.43 on bg, 3.06 on surface |

**Do not reuse light-mode border values in dark.** `#334155` and `#475569` both fail 3:1 against
`#0B1220` (1.81 / 2.47) and are the most likely thing to slip through.

## 2. Typography

Replace the single Roboto Flex family with the pairing. Self-host or preload; keep
`font-display: swap` (skill rule `font-loading`).

- **Display/headings:** Lexend 700/900
- **Body/UI:** Source Sans 3 400/500/600

Scale (Exaggerated Minimalism, tempered for a trust-driven corporate site):

| Role | Size | Notes |
|------|------|-------|
| Hero h1 | `clamp(2.75rem, 9vw, 7.5rem)` | weight 900, `letter-spacing: -0.04em` |
| Section h2 | `clamp(2rem, 4.5vw, 3.5rem)` | weight 800, `-0.03em` |
| h3 | `1.25–1.5rem` | weight 700 |
| Body | `1rem` / `1.6` | never below 16px on mobile |
| Eyebrow | `0.72rem` | `0.22em` tracking, uppercase — keep, recolor to `--accent` |

The skill's raw spec says `clamp(3rem, 10vw, 12rem)`. 12rem overflows Turkish compound headings
("İnşa Ediyoruz") at 375px — capped at 7.5rem deliberately.

## 3. Motion (dial 5/10 — Standard)

Existing framer-motion usage is sound and `useReducedMotion` is already wired in Hero. Keep the
approach, unify the constants:

- Micro-interactions **150–250ms**; section reveals **≤400ms**
- ease-out entering, ease-in exiting; exits ~65% of enter duration
- Stagger list/grid items **40ms** apart
- `transform`/`opacity` only — no width/height/top/left animation
- Every new animation respects `prefers-reduced-motion` (already handled globally in `index.css`)
